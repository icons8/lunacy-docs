These schemas describe the direct HTTP request bodies of a matching preview build. They are preserved from the generated application catalog; parser acceptance does not replace domain validation, target access, revision checks or work limits. Discriminators and semantic requirements are explained in the [complete v2 reference](https://lunacy.docs.icons8.com/plugin-api-v2/).

Source and provenance: [lunacy-plugins schemas](https://github.com/icons8/lunacy-plugins/blob/7b82b78118e2c66a474f3d556b171903af12bcbc/docs/schemas/README.md).
