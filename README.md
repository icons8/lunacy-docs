# Lunacy Documentation

This project is a collaboration to create the documentation for [Lunacy](https://icons8.com/lunacy), Graphic Design Software with built-in assets.

## Contribute

We're looking for your help editing and expanding it. In particular, we'll gladly accept:
* Spellchecks 
* Better illustrations
* New sections
* Video tutorials

## Icons8 assets inside Lunacy

Lunacy ships with the full Icons8 library, free to drag onto the canvas:

- **[1.5M+ icons](https://icons8.com/icons?utm_source=github)** in 132 styles — popular: [iOS 27](https://icons8.com/icons/ios?utm_source=github), [Color](https://icons8.com/icons/color?utm_source=github), [3D Fluency](https://icons8.com/icons/3d-fluency?utm_source=github)
- **[110,000+ illustrations](https://icons8.com/illustrations?utm_source=github)** in 345 styles — popular: [3D Casual Life](https://icons8.com/illustrations/styles/3d-casual-life?utm_source=github), [Cherry](https://icons8.com/illustrations/styles/cherry?utm_source=github), [Bouncy](https://icons8.com/illustrations/styles/bouncy?utm_source=github)
- **[Download Lunacy](https://icons8.com/lunacy?utm_source=github)** — free for Windows, macOS, Linux
